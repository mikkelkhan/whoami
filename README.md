# WHOAMI - Personal AI Assistant

A modern RAG (Retrieval-Augmented Generation) chatbot built using:

* Flask
* FAISS
* Sentence Transformers
* Groq LLMs
* HTML/CSS/JavaScript

This chatbot allows users to ask questions about a person, portfolio, documents, or custom knowledge base.

---

# Features

* Modern AI chat interface
* RAG-based retrieval system
* FAISS vector search
* Groq LLM integration
* Fast Flask backend
* Responsive mobile-friendly UI
* Real-time chat experience
* Typing animation
* Semantic document search

# RAG Workflow

```text
User Query
   ↓
Embedding Generation
   ↓
FAISS Vector Search
   ↓
Retrieve Relevant Chunks
   ↓
Send Context + Query to Groq LLM
   ↓
Generate Answer
```
